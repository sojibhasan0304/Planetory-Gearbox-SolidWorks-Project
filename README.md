# Planetary Gearbox Assembly with Integrated Rotary Motor

A complete 3D mechanical assembly and motion study of a planetary gearbox designed in SolidWorks. This project features a mechanical gear train driven by an integrated rotary motor applied to the handle input.

## 📝 Description
This repository contains the full 3D CAD files for a functional planetary gearbox system. The assembly utilizes interactive gear mates to accurately simulate the mechanical relationships between the central sun gear, revolving planet gears, and the main internal ring gear housing. Input torque is delivered via a rotary motor mounted on the handle mechanism, demonstrating mechanical advantage, speed reduction, and torque multiplication through the gear matrix.

## ⚙️ Project Specifications
* **CAD Software:** SolidWorks 2026 (Education Edition)
* **Main Assembly File:** `planetary_gearbox_colourSwap.SLDASM`
* **Input Source:** Integrated Rotary Motor attached to the handle
* **Core Components:** Central Sun Gear, Planet Gears, Main Ring Gear Housing, Carrier Plate, Handle Input

## 📂 Repository Structure
* `/` - Root directory containing the main assembly file (`.SLDASM`) and all individual component files (`.SLDPRT`).
* `/images/` - Folder containing visual documentation, drawings, and preview GIFs.
* **Note:** To prevent broken component links, do not move individual part files out of this root directory structure.

## 🚀 How to Use
1. Ensure you have **Git LFS** installed on your local computer before cloning.
2. Open SolidWorks and locate the root directory.
3. Launch the main assembly file: `planetary_gearbox_colourSwap.SLDASM`
4. Switch to the **Motion Study** tab at the bottom panel to play or simulate the rotary motor actuation.

## ⚠️ Collaboration Notice
Because SolidWorks CAD data consists of binary files, standard text-based Git merging is not supported. If you are collaborating on this project, please coordinate changes with team members beforehand to avoid file conflicts or data overwrites.
